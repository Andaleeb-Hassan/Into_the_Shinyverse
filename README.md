# Into the Shinyverse

An interactive statistical learning application developed as an **R-Fest project**, designed to introduce fundamental statistical concepts through hands-on exploration and visualization.

### Features
- **Diamonds:** Explore relationships between numerical and categorical variables using scatter plots, box plots, and bar charts based on the `ggplot2` diamonds dataset.
- **Association:** Learn the chi-square test of independence through observed and expected frequencies, hypothesis testing, p-values, critical values, and visualizations. Also includes odds ratios, confidence intervals, and Fisher's exact test for 2 × 2 tables.
- **Formula Sheet:** A concise reference of essential statistical formulas and definitions.

### Tech Stack
`R` · `Shiny` · `ggplot2` · `tidyverse`
